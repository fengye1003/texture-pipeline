# 规则图案的几何解算

> 适用：**轴对齐、规则重复**的图案（编织纹方砖、人字拼、错缝长条、格栅、砖墙…）。
> 目标：从一张参考图，得到**精确的边矩阵 + 周期**，从而可以程序化重建出绝对无缝的贴图。

## 1. 为什么不能"直接裁一块来平铺"

参考图通常是**裁出来的**：裁切位置和图案周期没有关系。直接平铺必然露缝。要么做无缝化（随机纹理那一套），要么**把图案的周期解出来**——后者对规则图案是精确解，而且能顺带拿到参数化的缝宽、块尺寸。

## 2. 三步

### 第一步：量网格 —— `analyze.py`

- 统计每列/每行的**亮像素占比**（缝比砖面亮），峰值处即缝；
- 相邻峰值的间距 = **模数**（本例 26.9px）；
- 同时给出配色直方图（砖面色 / 缝色）。

### 第二步：求边矩阵与周期 —— `extract-edges.py`

对每个"格点边界"取一个小邻域的最亮若干像素均值，与阈值比较，得到两张 0/1 表：

```
V[c][r] = 1  ⇔  第 c 条竖边界，在第 r 行带内画了线
H[r][c] = 1  ⇔  第 r 条横边界，在第 c 列带内画了线
```

再对这两张表**求最小周期**（逐行比较，找最小平移量使整表不变）。本例：**竖 5、横 5** ⇒ 单元 = 5×5 个模数。

> ⚠️ 注意边界：贴图边缘那几行/列可能是"被裁断"的，求周期时要允许它们不参与比较，否则永远求不出来。

### 第三步：合并成块并自检 —— `reconstruct.py`

把"中间没有线"的相邻格**合并成最大矩形**：

- 向右扩展：直到遇到竖线；
- 向下扩展：整行都不能有横线。

结果是一个矩形块列表。两个要点：

1. **跨周期边界的整块**：某些砖会跨过单元接缝（例如单元最右列与下一单元最左列其实是同一块砖）。**这正是它能无缝平铺的原因**，也是"按图片尺寸裁一块"会出错的地方。
2. **自检**：按重建结果画一张线掩膜，与原图的线掩膜逐像素比对，得到命中率（本例 95%；缺口主要来自 1px 线宽与抗锯齿）。

## 3. 从"解出来的几何"到贴图

`make-texture.mjs` 的做法是**在全局周期坐标上采样**：

- 像素坐标先对一个周期取模；
- 缝的判定用 `V/H` 表查（索引同样取模）；
- 砖内坐标由"跨接缝的块"归一化而来（所以跨界的砖在贴图里也是连续的）；
- 每块砖的色差、石材取料偏移都**按砖号固定** ⇒ 平铺后同一块砖到哪都一样，不会闪。

因为贴图**正好取一个周期**，可以严格证明无缝：把任一像素平移一个周期后重新采样，30 万随机点的最大差异为 **0**。

## 4. 实测参数示例（编织纹深色方砖）

| 项 | 值 |
|---|---|
| 模数 | 26.9 px（参考图 269×375，10×14 格） |
| 周期 | **5×5 模数**；单元内 **15 块砖**（尺寸 2+2+2+1+1+2+2+2+1+2+1+2+2+2+1 = 25 格） |
| 缝宽 | 模数的 **2.3%**（参考实铺照片实测） |
| 砖面 / 缝色 | `#302522` / `#716863`（实铺照片实测，缝色取**缝芯**） |
| 重建命中率 | 95.2%（1px 容差） |
| 无缝自检 | 平移一个周期，30 万点差异 **0** |

## 5. 边界

- 只处理**轴对齐**的缝；斜向、弧形、透视畸变的图案不适用（需要先做几何校正）。
- 前提是图案**真的规则重复**；"看起来像"但间距有 ±25% 抖动的（典型：AI 生图）求不出周期 —— 求不出来这件事本身就是一个有用的判据（见 `03-pitfalls.md` P9）。
